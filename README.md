# マンガ風コマ割りメーカー（komawari）

写真やイラストをコマ割りレイアウトに流し込み、各コマ下部の帯に台詞を入れた「マンガの1ページ風」画像を合成するツールです。

## 使い方

1. レイアウト（縦2コマ／横2コマ／3コマ／4コマ）を選びます。
2. 各コマに画像（PNG/JPEG/WebP）をアップし、任意で台詞・キャプションを入力します。
3. 「ページを作る」を押すと PNG（幅1000px）がダウンロードされます。

画像はコマの形に合わせて中央でトリミングされます。画像のないコマは灰色の空コマになります（キャプションだけでも表示されます）。

## フォントについて

日本語表示のため、実行時に Noto Sans CJK（notofonts の GitHub リポジトリ）からフォントファイルを取得し、`/tmp` にキャッシュして使います。取得に失敗した場合は、その旨のエラーを表示します。

## ローカル実行

```bash
pip install -r requirements.txt
python app.py
# http://localhost:5000
```

## テスト

```bash
python -m unittest discover -s tests
```

テストではフォント取得を行わず、ローカルの英字フォント（DejaVu Sans）で合成を確認しています。

## Render へのデプロイ

`render.yaml` 同梱。無料プラン（free）の Web Service としてデプロイできます（healthCheckPath: `/healthz`）。

## 制限事項（正直なところ）

- 吹き出し（丸いフキダシ）の自動配置はしません。台詞はコマ下部の帯キャプションとして表示する簡易仕様です。
- キャプションが長い場合は帯に収まるよう末尾が切り捨てられます。
- コマ割りは4種類の固定レイアウトのみです。不等分や自由な変形には対応していません。
- フォント取得は外部サイト（GitHub）への通信に依存します。アップロード画像は保存しません。
